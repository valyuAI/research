# Explainer video: when is restarting a search the best you can do?

`video.mp4` (narrated, 1080p30) explains this finding for a GCSE-level viewer. It starts from lost keys and builds up a random walker searching a line for a target. It covers the average search time (infinite without restarts), what a restart is and why it helps, fixed and random timers, and the rule "average search time = attempt length divided by success chance". It then poses the question of the best recipe over all timers. The running example is the paper's: spreading coefficient 1 and target map `2e^(-2x)`, where the best recipe is a random timer of rate 1 with average search time 1. The video presents the Evans-Ray conjugate prescription (square the success curve and rescale) as prior work. It then states the new global and unique optimality theorem and animates the key step, `u/v + v/u = 2 + (u - v)^2/(uv)` over a symmetric weight `min(x, y)`, crediting the pairing inequality to earlier work (Davila and Topp). It shows the competitor costs from `verification/resetting_verification.json`, the finite-room reversibility characterisation, and the exact three-room counterexample (`2332/4453`; rate 9/10 is lower by `761111595/7705213313411`). It is explicit about status. The main theorem and its converse have written proofs only. Lean checks only the finite pairing algebra and the three-room numbers. There is no peer review, and novelty is provisional. One line, that every fixed timer has infinite cost on this map, is the video's own calculation, and the video says so. Rebuild from the repository root with `python tools/video/render.py <this folder> --quality l --contact` for a silent preview, then `python tools/video/make_audio.py <this folder>` for narration (only changed clips are regenerated), then `python tools/video/render.py <this folder> --quality h --contact` for the final render, using the toolkit's Python environment (manim 0.22). `storyboard.md` holds the scene plan and the number ledger. The narration uses a synthetic voice.
