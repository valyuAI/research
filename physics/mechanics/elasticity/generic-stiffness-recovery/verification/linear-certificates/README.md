# Exact minor certificates for the two recursive rank bounds

The supplied 7 by 13 linear matrix `N2(w)`, with eight variables over
`Q(i)`, satisfies

```
dim {w : rank N2(w) <= 2} <= 2,
dim {w : rank N2(w) <= 3} <= 3.
```

These are affine algebraic dimensions. The same bounds hold after extension
to the complex numbers. They are upper bounds, not claims that either locus
has exactly the stated dimension.

## Reproduce without a computer algebra system

Copy these two files into the same directory and run:

```sh
python3 verify_certificates.py
```

- `minor_dimension_certificates.json` contains the matrix and eleven explicit
  polynomial identities in its original minors.
- `verify_certificates.py` uses only Python's standard library. Its arithmetic
  consists of pairs of `Fraction` values for `Q(i)` and sparse polynomials.

The checker recomputes every required determinant, reconstructs each identity,
checks leading monomials in graded reverse lexicographic order
`w0 > w1 > ... > w7`, and enumerates the variable covers. It neither imports
a CAS nor calls a rank, ideal-membership, or Groebner-basis routine. Run Python
without `-O`; the checker rejects optimized execution because it uses assertions.

## Why eleven identities suffice

Let `I_r` be the ideal generated by the original `(r+1)` by `(r+1)` minors.
Each verified target polynomial belongs to `I_r`, because the certificate
expresses it as a sum of those minors times constants or single variables.
Its leading monomial therefore belongs to the initial ideal of `I_r`.

If `J_r` is generated by the selected leading monomials, then
`J_r` is contained in the initial ideal of `I_r`. The standard equality of
dimension under passage to an initial ideal gives

```
dim Q(i)[w]/I_r = dim Q(i)[w]/in(I_r) <= dim Q(i)[w]/J_r.
```

For a monomial ideal in eight variables, the last dimension equals eight
minus the smallest size of a set of variables meeting every generator's
support. This follows by taking the minimal coordinate primes containing the
monomial ideal. The checker enumerates variable subsets in increasing order of
size until it has found all minimum covers.

For rank at most two, the six selected leading monomials are

```
w4^2*w7, w6^3, w5^3, w2^3, w1^3, w0^3.
```

Every variable cover must contain `w0,w1,w2,w5,w6` and one of `w4,w7`.
The minimum cover size is six, giving dimension at most two.

For rank at most three, the five selected leading monomials are

```
w6^4, w5^4, w2^4, w0^4, w1*w4^2*w7^2.
```

Every cover must contain `w0,w2,w5,w6` and one of `w1,w4,w7`.
The minimum cover size is five, giving dimension at most three.

No complete Groebner basis, reverse ideal containment, or correctness of the
original basis computation is needed for this argument.

## Scope and provenance

The embedded matrix matches `next_normal_matrix` in
`../recursive_normal_borel_checks.json` entry for entry. This certificate checks
the two bounds for that matrix. The derivation of the recursive normal matrix,
the earlier rank strata, and the global inverse problem are separate proof
obligations. These eleven identities alone do not prove the global theorem.

Previously saved Singular output supplied candidate polynomials, not trusted
membership assertions. `build_certificates.py` independently generated exact
linear combinations of original minors using rational linear algebra.
`build_quintic.py` then generated the quintic identity using polynomial division
and exact linear algebra. The final quintic is a sum of 524 terms, each a
constant times one variable times an original 4 by 4 minor. The generators use
SymPy, but neither generator is required or trusted when checking the final
certificate.

`independent_verification.json` and its log record the successful eleven-identity
check. `certificate_manifest.json` records input and artifact hashes. The
workspace and intermediate files are discovery aids and are not needed in a
portable verification package.
