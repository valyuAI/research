## How to read the evidence

Written proofs, exact computations and Lean formalizations have different scopes. A saved search result is not automatically a certificate. Each finding records the actual checks, known prior work and limitations. The expanded Lean library has passed a 153-declaration axiom audit; the independent six-checker replay covers the earlier 121-declaration version only.

Completed videos include narration, subtitles, editable animation code and retained audio. Metadata, full decode, timing and frame-inspection checks are recorded in their folders. Listening review has not been performed.

One unfinished draft, optional covering and quartet searches, and earlier biology explorations are excluded from the package and discovery counts. The [machine-readable inventory](collection.json) is the source for this navigation.
