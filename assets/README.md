# Research banner

The banner uses Valyu's Source Serif 4, Schibsted Grotesk and Spline Sans Mono typography, with ink, plum and citron on a warm white ground. Letterforms are outlined so the SVG renders without external fonts.

The lattice shows the 64 words in `{0, 1, 2, 3}³`. A node is plum exactly when its coordinate sum is zero, or greater than one and congruent to one modulo three: the paper's coloring with `p = 3`.
