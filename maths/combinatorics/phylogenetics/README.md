# Phylogenetic trees

[Up one level](../README.md)

Combinatorial questions about tree agreement and balance. These are mathematical tree results, not biological discoveries.

- [Why integer tree-balance weights fail](colless-like-integer-weights/): Nonnegative weights with f(2), f(3), f(4) in one cyclic real lattice cannot yield a sound Colless-like index. The result does not exclude all real-valued weights.
- [Common quartets in evolutionary trees](common-quartet-number/): h(3)=14; a single-exponential general upper bound with base (1+sqrt(13))/2; 23<=h(4)<=28. Lean checks only the sharp potential inequality and equality witness. Global optimality and h(4) remain open.
