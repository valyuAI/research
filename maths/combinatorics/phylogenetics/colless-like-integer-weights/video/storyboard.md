# Whole-number weights and a false zero

Audience: GCSE graduate. Narration: Cedar. Exact spoken text is in narration.json; one clip per beat, measured after synthesis. All diagrams are teaching constructions, not biological observations.

| Scene / clips | Narration and visual action | New understanding / evidence |
|---|---|---|
| Trees / c01-c03 | Draw FS(2,2) and FS(6), identify root and leaves, highlight identical child structures. | Rooted shape and full symmetry; paper section 1. |
| Weights / c04-c06 | Label every vertex with children plus one. Accumulate 3+6+4 and 7+6 into 13. | Weighted size can lose shape information; verified example. |
| FalseZero / c07-c10 | Physically join trees under one root; reveal zero at each fork. Ask whether different integer weights help. | A collision produces an unsound index for every permitted dissimilarity; paper proof. |
| Recipes / c11-c14 | Transform FS(2,3) into FS(3,2), preserving six leaves. List all six permutations of 2,3,4; extend to two of each and 90 recipes. | Order changes shape while product fixes leaves. |
| Counting / c15-c17 | Build factorial quotient; show schematic bins by letter counts and lower bound. | Exact multinomial count versus 27^m exponential base. Bars are explicitly schematic. |
| Boxes / c18-c22 | Cross out common leaf terms; count 1+2+4<8 on a tree; map integer sums onto boxes; move four dots into three boxes. | Why arbitrary leaf weights cancel and pigeonhole applies to internal sums. |
| Crossing / c23-c25 | Plot exact log ratio N_m/(5*24^m+1); highlight first crossing. Return to joined example. | Exponential growth forces a collision for every fixed M; example M=5 is not the theorem's restriction. |
| Scope / c26-c31 | State common-unit condition, prior collision, rank-two grid, recap and end card. | Hand theorem, illustrative computation, prior work and unresolved rank-two boundary. |

Comprehension review: terms are introduced with pictures before formulas; factorial receives an explicit definition; the two-tree example remains visible across the first three scenes. The detailed multinomial lower bound and asymptotic comparison are explained, but this is an exposition of the hand proof, not a formal proof checker. No audience test is claimed.
